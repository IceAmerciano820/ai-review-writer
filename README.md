# ai-review-writer

医美 / 本地生活场景的**体验文案生成工具**。填写项目名称与机构名称，选择条数、风格和字数，生成自然口语化的分享文案，并对违禁词与绝对化用语做实时校验。

在线体验：https://yongyuanmeili.netlify.app

## 为什么做这个

医疗、医美类内容在广告合规上有明确红线：不能使用"最好""第一""根治""永久"等绝对化或承诺性表述。人工写文案时很容易顺手写进去，事后被平台判违规。

所以这个工具做的不只是"生成"——生成之后还有一道**自动校验**：命中违禁词会高亮并给出提示，让写作者在发布前就能发现风险。

## 功能

- **多风格**：亲切自然 / 专业严谨 / 活泼简短 / 精致文艺，风格会真实改变生成提示词的语气
- **多字数**：短评 40-60 字 / 中评 80-120 字 / 长评 200-250 字
- **多条生成**：一次 1 / 3 / 5 条，每条分配不同的切入角度（进店流程、操作体感、术后变化、服务环境、方案沟通），避免雷同
- **违禁词检测**：内置词表 + 高亮显示；带白名单机制，避免把"第一次来做"这类正常表达误判为违禁词"第一"
- **历史记录**：本地保存最近 20 条，可单条复制或删除
- **一键复制**：每条文案独立复制按钮

## 架构

```
浏览器（静态页面）
      │  POST /.netlify/functions/generate
      ▼
Netlify Function（Node，CommonJS）
      │  从 process.env.DEEPSEEK_API_KEY 读取密钥
      ▼
DeepSeek API
```

**密钥只存在于服务端环境变量**，前端代码和网络请求里都不含 API Key —— 这是本项目最容易踩坑、也最值得说明的一点：如果直接在页面里调用第三方大模型接口，任何访客打开源码就能拿到密钥。

## 工程要点

- Netlify Function（CommonJS `exports.handler`）代理上游调用，前端只传业务参数
- 多条生成使用 `Promise.all` 并发，5 条文案整体耗时约 3 秒（串行会逼近函数超时上限）
- `AbortController` 设置请求超时，上游异常统一转成可读错误信息
- 入参校验：必填项、字段长度上限、条数上限（防刷）
- 发布目录收敛到 `public/`，配置文件、函数源码、环境变量文件都不会被当作静态资源暴露

## 本地运行

```bash
npm install -g netlify-cli
cp .env.example .env      # 填入 DEEPSEEK_API_KEY
netlify dev               # http://localhost:8888
```

## 部署

```bash
netlify env:set DEEPSEEK_API_KEY "sk-..."
netlify deploy --prod
```

## 合规说明

本工具用于**整理真实体验的文字表达**，不生成虚假评价。内置的违禁词检测只是辅助提示，不能替代人工审核，最终内容请自行确认后再发布。

## 技术栈

纯 HTML + 原生 JavaScript（无框架、无构建步骤） / Netlify Functions / DeepSeek API
